# NEON BURROW — Crypto Clicker

Мобильный браузерный кликер в неоновой крипто-стилистике. Чистый HTML, CSS и JavaScript, без сборщика и внешних библиотек.

## Запуск
1. Распакуйте архив.
2. Откройте `index.html` в современном браузере.
3. Для публикации на GitHub Pages загрузите все три файла в корень репозитория.

На iPhone можно открыть `index.html` через файловый менеджер/подходящее локальное веб-приложение. Для более надёжной работы сохранения и таймеров рекомендуется запускать через локальный HTTP-сервер или разместить на GitHub Pages.

## Что реализовано
- Тап по SVG-персонажу, критические тапы и всплывающие числа.
- Энергия с автоматическим восстановлением.
- Магазин улучшений с ростом цены, пассивный доход и оффлайн-начисления (до 30 дней).
- Скины, покупка и выбор активного оформления.
- Сейф-код с таймером и ежедневным ограничением награды.
- Ежедневная награда раз в 24 часа и комбо-набор.
- Профиль, статистика, автосохранение в `localStorage`.
- Адаптивная мобильная вёрстка, безопасные зоны iPhone, отсутствие прокрутки страницы; внутренние вкладки магазина могут прокручиваться.

## Важно
Прогресс хранится локально в браузере на конкретном устройстве. Очистка данных сайта/браузера удалит сохранение. Это офлайн-игра: монеты условные, серверной синхронизации и реальных криптовалютных операций нет.
